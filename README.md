# VK RP Moderator

VK-бот-модератор с RP-командами.

## Требования

Python 3.14+

## Установка

Создать виртуальное окружение:

python -m venv .venv

Windows:

.venv\Scripts\activate

Установить зависимости:

pip install -r requirements.txt

## Настройка

Переименовать:

.env.example

в:

.env

Указать:

VK_TOKEN=токен_сообщества
OWNER_ID=ваш_vk_id

## Запуск

python main.py
